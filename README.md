# Oceanside rental listings

Listing site for the two rentals at 1821 S Ditmar St, Oceanside, CA.

Live site: https://oside-rentals.pages.dev

- `index.html`: the whole site (both listings, map, neighborhood)
- `01.jpg`–`16.jpg`: photos of the 2 bed / 2 bath (Unit #1)
- `studio/`: photos of the studio (Unit #2)
- `map-light.webp`, `map-dark.webp`: location map

Hosted on Cloudflare Pages. Every commit to `main` redeploys automatically. No build step.
